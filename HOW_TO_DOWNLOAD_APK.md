# 📱 How to Download Your APK (Phone Only)

GitHub will automatically build your APK in the cloud! Here's how to download it:

## 🚀 Method 1: From GitHub Releases (EASIEST)

1. **On your phone, open your browser** and go to:
   ```
   https://github.com/dstavad2-ui/NTRLI_Superbot/releases
   ```

2. **Find the latest release** (will be named like "NTRLI Superbot v1.0.X")

3. **Scroll down to "Assets"**

4. **Tap the APK file** to download (name: `ntrli_superbot-1.0.0-debug.apk`)

5. **Install the APK:**
   - Open your Downloads folder
   - Tap the APK file
   - If prompted, enable "Install from Unknown Sources"
   - Tap "Install"

6. **Launch the app** from your app drawer!

## 🔧 Method 2: From GitHub Actions

1. **Go to your repository:**
   ```
   https://github.com/dstavad2-ui/NTRLI_Superbot
   ```

2. **Click "Actions" tab** at the top

3. **Click the latest "Build Android APK" workflow**

4. **Scroll down to "Artifacts"**

5. **Download "NTRLI-Superbot-APK"**

6. **Extract the ZIP file** and install the APK

## ⚡ When Does It Build?

The APK builds automatically when you:
- Push code to the `claude/create-app1-folder-sbGsL` branch
- Push to `main` or `master` branch
- Or you can trigger it manually:
  - Go to Actions tab
  - Click "Build Android APK"
  - Click "Run workflow" button

## ❓ Troubleshooting

**Build not starting?**
- Check the Actions tab for any errors
- The workflow triggers on push to the branch

**Can't find the APK?**
- Wait 10-15 minutes for build to complete
- Check both Releases and Actions → Artifacts

**APK won't install?**
- Make sure you enabled "Install from Unknown Sources"
- Check you have Android 7.0+
- Make sure you have enough storage space
